matemática visual
um pequeno livro de demonstrações interativas — conceitos de matemática, cálculo e física explorados através de gráficos que respondem ao toque, não a textos que se leem passivamente.

a ideia
a maioria do material de matemática ensina através de fórmulas e depois, se sobrar espaço, mostra um gráfico estático como ilustração. aqui a ordem se inverte: a visualização é o argumento, e ela responde à interação — arrastar, dar play, comparar — em vez de só decorar o texto.
cada demonstração é um arquivo HTML autocontido, sem dependências, pensado pra rodar direto no navegador.

rodando localmente

```
git clone https://github.com/dadaset/matematica-visual.git
cd matematica-visual
open index.html
```
